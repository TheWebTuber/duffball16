01 // WHAT IT DOES

TURN A REMOTE SERVER INTO A LOCAL LINK.

Some Bedrock console versions do not offer a normal “Add Server” box. TidusLink runs on another device in your home network and advertises the remote server as a LAN game your compatible console can discover.

01ADDRESS + PORT

Use the server you want

Paste a hostname such as play.example.net or an IP address, then enter its Bedrock UDP port.

02CUSTOM DISPLAY

Name it your way

Choose a clear LAN name and subtitle so the connection is easier to recognize when you open the LAN/Friends list.

03LOCAL ONLY

Keep it simple

No account is required. TidusLink does not keep a cloud server history or global usage tracker.

02 // QUICK SETUP

FROM DOWNLOAD TO LAN LIST.

Keep the computer running TidusLink and the console on the same local network while you connect.

  1. 01
    Install TidusLink

    Windows users can download and extract the ZIP. Linux users can use the one-command installer below, which automatically chooses x64 or ARM64.

  2. 02
    Start TidusLink

    On Windows, run the app and allow private-network firewall access if asked. On Linux, simply open a terminal and type tiduslink.

  3. 03
    Enter server details

    Paste the Bedrock server address and UDP port, then choose the LAN name and subtitle you want to see.

  4. 04
    Start LAN Link

    Press Start LAN Link and leave TidusLink running while the console connects.

  5. 05
    Open Bedrock

    On the console, open Play and look in the Friends/LAN area for the name you chose.

  6. 06
    Join

    Select the LAN entry. TidusLink relays that local connection to the remote Bedrock server you entered.

Nothing showing up?

Check that both devices are on the same home network, no other LAN-connector service is already using UDP port 19132, firewall access is allowed on the private network, and your router is not isolating Wi‑Fi/LAN clients. Restarting Bedrock can also refresh LAN discovery.

LINUX QUICK INSTALL // RECOMMENDED

One command. Ready to run.

Works on supported Linux x64 and ARM64 systems. The installer detects your architecture, downloads the correct TidusLink package, verifies its SHA-256 checksum, installs it, and creates the tiduslink command.

AUTO-DETECTS x64 / ARM64
INSTALL OR UPDATE Run this in your Linux terminal 
curl -fsSL https://duffball16.com/install-tiduslink.sh | bash

Running the same command again later installs the current v1.1 package over your existing TidusLink installation.

What will the command do?

The script is downloaded from Duffball16.com and run with Bash. On systems where ~/.local/bin is not already available in your terminal, the installer may ask for administrator permission once so it can make the tiduslink command available immediately.
