How do I use a backup?

Choose a date and select “Download ZIP”. Extract the ZIP to see the saved world files. Use a Minecraft edition and version compatible with that world. This is all server backups from the Duffball16 SMP, so you’ll need to be on the same edition and version as the server was at that time or you can try updating that world to a newer version of Minecraft. Reminder that this is a paper server, so you know what you are getting into. If you are unsure, ask in the Discord for help.

Keep a separate copy of your existing world before importing a save. Need the right version or help with the files? Ask in the Duffball16 Discord.
